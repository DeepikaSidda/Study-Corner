How it works

Four AI agents, and code that checks their work

Built with Strands Agents on AWS. The agents write; deterministic checks decide what you are allowed to see.

Listen

Amazon Transcribe turns speech into text, with a time on every line.

Look

It spots each new slide or board and reads what is written on it.

Write

Agents write the notes and the quiz, reading the lecture through tools.

Check

Code and a judge agent confirm every answer before it is kept.
